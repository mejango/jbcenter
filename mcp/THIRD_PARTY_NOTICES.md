# Third-party source references

`data/knowledge.json` and `data/development.json` contain source and documentation from Juicebox ecosystem repositories. Each entry records its repository, path, revision, file hash, original text and available license information. Original SPDX and copyright notices remain in the text.

These bundles are reference material. This repository does not relicense their contents. `NOASSERTION` or missing license information means no license was inferred; it is not a grant of rights. The source manifest in [docs/SOURCES.md](docs/SOURCES.md) and webclient manifest in [docs/WEBCLIENTS.md](docs/WEBCLIENTS.md) describe coverage.

Runtime dependencies retain their package licenses and notices in `node_modules`; exact dependency versions and integrity values are recorded in `package-lock.json`. A license for the newly authored repository code has not yet been selected. Review licensing before public redistribution of the combined artifact.
