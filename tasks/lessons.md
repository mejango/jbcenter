# Lessons

## 2026-11-12: A flat directory still needs one organizing axis
The first flat home page flowed seven sections of different kinds through masonry columns, and jango found it disorganized. Flattening removes clicks but not structure. Give a directory one axis the reader already holds (here the audience: use, build, automate), one fixed column per value, small sub-groups inside, and move reference material (audit, source, unfinished) to a separate band below.

## 2026-11-12: Sub-groups need parallel labels, and a row needs one label
Inside the three audience columns, each column had its own three group names (Apps, Launch, Learn; Start, Code and data, Center APIs; Connect, Instructions, Act safely) and each row carried two labels of equal weight. jango asked for something more streamlined. Use the same group names in the same order in every column so the reader learns the structure once, and give each row one label (the destination) plus a quiet descriptor. A test now requires every column to use the shared group titles.
