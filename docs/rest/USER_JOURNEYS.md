# Choose a journey

Center's REST reads and preparation need no account or API key.

| I want to | Use | Then |
| --- | --- | --- |
| Make a first request | [Quickstart](QUICKSTART.md) | Keep the source and block each response names |
| Find a project | [Indexed reads](INDEXER.md), or MCP search | Show the source and how fresh it is |
| Inspect a project's current configuration | [Contract reads](CONTRACTS.md) | Read values at the block returned |
| Prepare a payment or management action | The operation catalog, then [an unsigned draft](TRANSACTIONS.md) | Approve and send with Signa or your wallet |
| Check a project linked across chains | [Omnichain projects](OMNICHAIN.md) | Each chain keeps its own accounting |
| Publish a project before deploying it | [Project intents](PROJECT_INTENTS.md) | Center stores the signed, frozen launch |
| Deploy a published project | [Sponsored or self-paid deploy](PROJECT_INTENTS.md#sponsored-deploy) | Center records the deployment |
| Publish metadata | A browser upload from an approved app, or MCP publication | Content on IPFS is public |
| Connect an agent | [Agent guide](AI_GUIDE.md) | Prepare, review, hand off |
| Manage identity, devices or app permissions | [Signa](https://signa.center) | Signa owns accounts and recovery |
| Recover an uncertain payment | The service or wallet that sent it | It reconciles the original attempt |
