## Goal

Every Juicebox app should offer two ways in: **a passkey account powered by juicebox.center**, or **a direct wallet connection**. Package that as part of the Juicebox SDK and use it in Homerun and Beep. The modal should feel like the original Para modals Beep had (a calm, inline, app-styled dialog), but instead of email, phone and socials the only hosted option is the passkey. Copy says "account", never "wallet", for the passkey account; "wallet" is only for an external wallet.

## What to build (my recommendation; confirm with me before starting)

1. **Publish the Center client properly** from the Center repo (`@juicebox/center-client` to npm, or a versioned tarball the SDK can depend on) so the SDK does not copy Center's protocol code. Center stays the source of truth for the handoff protocol.
2. **SDK**: a new package `@bananapus/nana-sdk-connect` (or a `./connect` area in react if the maintainers prefer) with:

Themeable through CSS variables so Homerun (Tailwind) and Beep (plain CSS, palette `#fffef8/#20221d/#759744`) both look native.
   - callback helper for the app's `/center/callback` page.
